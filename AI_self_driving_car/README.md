# AI Self-Driving Car using OpenCV

## Project Description
This project simulates a basic AI Self-Driving Car system using Python and OpenCV.

It detects road lanes from a video using:
- Canny Edge Detection
- Hough Line Transform

The system highlights lane lines in real time.

---

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib

---

## Features
- Lane Detection
- Edge Detection
- Real-time Video Processing
- Self-driving car simulation

---

## How to Run

1. Install libraries

```bash
pip install opencv-python numpy matplotlib
```

2. Run the program

```bash
python lane_detection.py
```

---

## Output
The project displays:
- Road lane markings
- Real-time lane detection video
